# 易学日课

从零开始学《周易》的互动网页。单文件，无需构建，打开 `index.html` 即可使用。

## 手机 / 电脑访问

- **Claude 在线版**（私有，需登录本人 Claude 账号）：https://claude.ai/artifact/7t4oebj9T9r9jDUAkxp6KK
- **GitHub Pages 公开版**：https://liyf1640.github.io/Yijing/
  需先在仓库 Settings → Pages 中选择 `main` 分支、根目录（`/`）并保存，一两分钟后生效。公开后任何人无需登录即可打开。

建议手机上用浏览器打开后“添加到主屏幕”，当作小应用每天使用。

- **今日**：按日期固定生成一卦一爻，附卦辞、象辞、白话和学习路径
- **起卦**：三枚铜钱法，自动判断本卦、变爻、变卦，并按朱熹《易学启蒙》的规则给出该读的经文
- **八卦**：八经卦的取象、性情、人伦、方位与记忆口诀
- **六十四卦**：通行本卦序总览，每卦含卦辞、大象、六爻爻辞；可标记“已学”记录进度
- **练习**：看图认八卦、认六十四卦、辨上下卦

经文采用通行本《周易》，白话为入门性概括。学习进度和起卦记录只保存在浏览器本地。
